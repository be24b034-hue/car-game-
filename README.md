# 🚗 Car Coin Collector

A simple car game made using GDevelop.

## 🎮 About the Game

In this game, you control a car and explore the environment while collecting coins.

The main goal is to roam around the map and collect as many coins as possible.

## 🕹️ Gameplay

- Drive the car around the map
- Explore the environment
- Collect coins
- Try to collect as many coins as possible

## 🛠️ Made With

- GDevelop
- 3D Game Development

## 🎯 Goal

This is one of my beginner game development projects, created to learn the basics of game development and game mechanics.
